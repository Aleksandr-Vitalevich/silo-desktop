# ___Silo-Desktop V2___
---
Проект является своеобразным хранилищем для данных. Использует концепцию одна копия -> один пользователь . Поскольку это сейф для данных рекомендация сохранить ваш логин и пароль чтобы не потерять доступ к данным . Восcтановить их не получится .

## ___Пакет db_manager___

> Содержит логику работы с базой данных
- Проект использует sqlite3 в корне проекта при первом запуске создается файл БД `silo.db`
- В программе может быть зарегестрирован только один пользователь , логин и пароль лучше записать поскольку шифрование данных происходит на основе пароля и восстановить его не получится.

## ___Пакет utils___

- Содержит утилиты такие как декораторы `logger.py`, `input_cleaner.py`, `retry.py`
- логику шифрования смотри модуль `security.py`

## ___Пакет view___

> Интерфейс программы. Компоненты интерфейса<br>
- Данные (Сохранение , просмотр, удаление ваших паролей , логинов и остального что хотите сохранить)
- Дневник (Можете писать свои мысли , идеи). 
- Выход меню выхода
